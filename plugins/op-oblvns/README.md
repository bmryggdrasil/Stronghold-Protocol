# 干员拓展：丰川祥子（Ave Mujica／Oblivionis）

Manifest 2 内容插件，为自选编队提供 6★ 近卫／领主丰川祥子。玩法记录使用独立的
`char_x_op_oblvns_oblvns` 标识；头像、技能图标、Front/Back 模型和语音借用官方
`char_4182_oblvns` 资源，不占用或覆盖同名官方干员的玩法标识。

## 启用与外观

房主在等待室「插件」中启用「干员拓展：丰川祥子」，再到「干员调配 → 自选编队」选择。
默认使用本体外观。安装并启用 `official-skins-01`、`official-skins-02` 后，可在
官方时装入口切换「旋律的主人」；时装按当前玩家保存，也可随时还原默认外观。

这位联动干员的官方语音表只提供日语联动配音。在默认中文环境中，跟随全局会回退到
已安装的日语；「试听」和对局使用同一语言解析流程。本次安装的是资源管线支持的
12 个战斗语音槽。补装资源可使用：

```sh
node tools/fetch-assets.mjs --only-operator=char_4182_oblvns --strict
```

## 战斗行为

持续演奏音符，有敌人时追踪，无目标时先自由飞行并搜敌；命中时才结算伤害。
音符离开攻击范围一段时间且没有追踪目标后消散。音符数量提供 Ave Mujica 成员的穿透加成，
祥子同时为自身范围内干员提供攻击速度光环。

- **S1 新月的苏醒**：按扇形依次演奏八颗法术音符，倍率随序列递减；可储存两次充能，
  充满后自动释放一次。
- **S2 满月的舞会**：钢琴与风琴姿态切换。钢琴提升攻击、加快音符并产生物理穿透；
  风琴提升攻击速度，演奏较慢的法术音符。Fever 期间使用当前音色的二连击。
- **S3 残月的余响**：扩大范围，同时演奏两颗物理和两颗法术音符，按敌方防御与法抗选择目标；
  命中展示晶格和音爆。Fever 期间为 Ave Mujica 成员提供锁血守护，并在结束时处理延迟退场。

Ave Mujica 共享 450 点 Fever 能量槽，触发后持续 20 秒，使用玫粉技力条和舞台效果。
具体技能、天赋、培养与模组数值以当前插件数据及界面说明为准；模拟器沿用官方的自动操作时序。

实现入口为 `server/sim/content/custom/op-oblvns.js`。真实插件组合、音符伤害、姿态和光环回归位于
`test/plugins/op-custom-battle.test.js`；客户端音符轨迹及命中特效回归位于 `test/render/fxoblvns.test.js`。
