# 干员拓展：丰川祥子（Ave Mujica / Oblivionis）

本扩展包遵循官方 Manifest 2 插件标准构建，为游戏提供 6★ 领主近卫干员「丰川祥子」及其全套专属战斗机制。

---

## 一、干员基础信息
- **干员代号**：丰川祥子（Oblivionis）
- **职业 / 分支**：近卫 / 领主（Lord）
- **稀有度**：6★
- **特性**：可以进行远程攻击，但此时攻击力下降至 80%（阻挡或自身格/前方格攻击时 100% 伤害，可对空）。
- **素材来源**：基于官方资源引用机制（`art.ref: "char_4182_oblvns"`），自动复用官方高清立绘、Spine 骨骼与全套语音。

---

## 二、战斗机制与技能特色

### 1. 专属普攻：自由追踪音符
- 攻击范围内有敌人时发射追踪音符；无目标时发射扩张正弦轨迹的自由音符并自动搜敌，发射时立即回复 1 点技力且不播放攻击动作；
- 离开攻击范围且 1 秒内无目标才自然消散，音符伤害于命中时结算并缓存发射时倍率。

### 2. 一技能【新月的苏醒】（八音符齐奏）
- 充能 2 次，自动释放；
- 从左至右呈扇形依次发射 8 颗音符，伤害随序列递减，造成法术伤害。

### 3. 二技能【满月的舞会】（双音色姿态切换）
- 点击手动切换姿态：
  - **钢琴音色**：攻击力大幅提升（+75%），音符命中后具备穿透效果，造成物理伤害；
  - **风琴音色**：攻击速度大幅提升（+110 ASPD），造成法术伤害；
- Fever 状态期间，当前音色的音符升级为二连击。

### 4. 三技能【残月的余响】（四音符齐奏与锁血守护）
- 攻击范围大幅扩大，祥子脚下升起专属玫粉舞台光环（`stageLight`）；
- 每次普攻同时演奏钢琴与风琴，发射 2 颗物理与 2 颗法术高倍率音符（物理音符优先追踪高魔抗敌人，法术音符优先追踪高护甲敌人）；
- 命中引发红粉晶格与红紫音爆特效（`musicBurst`）；
- **锁血守护**：Fever 期间，场上 Ave Mujica 成员受致命伤免死锁血，直至 Fever 结束统一退场。

### 5. 全队 Fever 机制与专属 UI
- Ave Mujica 共享 450 点 Fever 能量槽，普攻与技能命中持续累积；
- 满 450 点触发持续 20 秒的 Fever 状态：
  - 成员技能无消耗无限释放；
  - 战斗界面技力条呈现标志性的玫粉色（`#ff4bb8`）；
  - 全屏触发舞台音浪共鸣。

---

## 三、启用方法
1. 房主在建房或等待室界面打开「**房间插件** / Room Plugins」设置；
2. 勾选启用「**干员拓展：丰川祥子**」；
3. 进入「自选编队（DIY）」即可挑选丰川祥子加入对局阵容；
4. 历史已保存过丰川祥子编队的玩家将自动平滑迁移，无需重复配队。
