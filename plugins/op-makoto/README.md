# 干员拓展：结城理（Persona 3 Reload / Makoto Yuki）

本扩展包遵循官方 Manifest 2 插件标准构建，为游戏提供 6★ 傀儡师特种干员「结城理」及其全套 Persona 召唤机制。

---

## 一、干员基础信息
- **干员代号**：结城理（Makoto Yuki）
- **职业 / 分支**：特种 / 傀儡师（Dollkeeper）
- **稀有度**：6★
- **时装配置**：固定使用官方「见证荣光」时装（`char_4217_makoto@p3r#1`）。
- **素材来源**：基于官方资源引用机制（`art.ref: "char_4217_makoto"`），自动复用官方立绘、双人格 Front/Back Spine 动作模型及 14 条日语语音。

---

## 二、战斗机制与技能特色

### 1. Persona 召唤机制与傀儡师特性
- 受到致命伤害时不撤退，切换为替身 Persona 继续战斗，替身持续一定时间后重新唤醒本体；
- 具备完整的 Persona 召唤、转换与收回动作序列。

### 2. 一技能【俄耳甫斯·突击】
- 召唤初代 Persona 俄耳甫斯发动突击，造成范围物理伤害并击退敌人；
- 具备优秀的控场与阻滞能力。

### 3. 二技能【塔纳托斯·死神处决】
- 召唤死神塔纳托斯降临，对范围内生命值较低或带有负面状态的敌人造成高额真实伤害与斩杀处决判定；
- 伴随全屏黑暗撕裂暗影特效。

### 4. 三技能【人格面具觉醒 / 盟约总攻击】
- 双人格快速切换，攻击附带弱点转化判定；
- 触发 P3R 经典的【S.E.E.S. 盟约总攻击（All-Out Attack）】，全屏爆发极高额的全属性毁灭打击与终结特写。

---

## 三、启用方法
1. 房主在建房或等待室界面打开「**房间插件** / Room Plugins」设置；
2. 勾选启用「**干员拓展：结城理**」；
3. 进入「自选编队（DIY）」即可挑选结城理加入对局阵容；
4. 历史已保存过结城理编队的玩家将自动平滑迁移，无需重复配队。
