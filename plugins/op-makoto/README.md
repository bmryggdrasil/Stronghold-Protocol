# 干员拓展：结城理（Persona 3 Reload）

Manifest 2 内容插件，为自选编队提供 6★ 特种／傀儡师结城理。玩法记录使用独立的
`char_x_op_makoto_makoto` 标识；头像、技能图标、Front/Back 模型和语音借用官方
`char_4217_makoto` 资源，不占用或覆盖同名官方干员的玩法标识。

## 启用与外观

房主在等待室「插件」中启用「干员拓展：结城理」，再到「干员调配 → 自选编队」选择。
默认使用本体外观。安装并启用 `official-skins-01`、`official-skins-02` 后，可在
官方时装入口切换「见证荣光」；时装跟随当前玩家的选择，不固定覆盖其他玩家。

这位联动干员的官方语音表只提供日语联动配音。在默认中文环境中，跟随全局会回退到
已安装的日语；「试听」和对局使用同一语言解析流程。本次安装的是资源管线支持的
12 个战斗语音槽。可用下面的命令补装其资源，保留其它干员已安装的资源：

```sh
node tools/fetch-assets.mjs --only-operator=char_4217_makoto --strict
```

## 战斗行为

受到致命伤时切换为不阻挡的替身，通常持续 20 秒后返回本体；主动技能也可进入替身。
替身结束后，S.E.E.S. 成员周围范围内的敌人承受结城理攻击力相关的真实伤害总攻击。
该效果按成员范围结算。

- **S1 俄耳甫斯的竖琴**：替身使用俄耳甫斯。通常造成法术伤害；范围内有生命低于一半的
  友方干员时，优先治疗。
- **S2 塔纳托斯的囚锁**：替身使用塔纳托斯，攻击多个目标并有概率施加恐惧；范围内恐惧中的
  敌人生命低于攻击力相关阈值时触发处决。
- **S3 开辟明日的剑刃**：先使用塔纳托斯造成弱点伤害，再次开启技能或受到致命伤时转换为
  俄耳甫斯，为范围内队友提供治疗及闪避。不同 Persona 使用各自的模型动作和效果。

技能、天赋、培养与模组数值以当前插件数据及界面说明为准；模拟器沿用官方的自动操作时序。
实现入口为 `server/sim/content/custom/op-makoto.js`，真实插件组合与对局回归位于
`test/plugins/op-custom-battle.test.js`。
